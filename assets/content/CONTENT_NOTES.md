# 콘텐츠 제작 노트

이 폴더의 `stories.json` / `characters.json` / `sites.json` 는 LLM 초안에서 출발했으나,
2026-08-31 확장 작업에서 **전 23편을 한국사데이터베이스(db.history.go.kr) 원문과 대조**해
다시 썼다. 그럼에도 최종 책임은 사람 감수에 있으므로 배포 전 아래를 확인한다.

## 2026-08-31 확장·정정 내역

23편 전부를 사료 기반으로 확장했다(평균 989자, 총 22,748자). 확장 재료는 원문에 실제로
있는 요소 — 연도·간지, 관직명, 직접 인용 대사, 세주에 병기된 이설 — 로만 채웠다.

원문 대조 과정에서 **기존 콘텐츠의 사실 오류를 다수 바로잡았다.**

| 대상 | 고치기 전 | 사료 |
|---|---|---|

| 첨성대 | "농사의 때", "백성의 달력", "동양 최고 천문대" | 고대 기록은 「별기」의 `是王代鍊石築瞻星臺` 열두 글자뿐. **용도 언급 없음**. '천문을 살핀다'는 1530년 신증동국여지승람이 처음 |
| 월지 | "문무왕 14년에 동궁을 짓고 그 안에 못을 팠다" | 못은 **674년 2월**, 동궁 창건은 **679년 8월**로 별개 사건 |
| 월지 | 을제 등장 | 을제는 **선덕여왕 원년(632)** 인물이라 674년에 있을 수 없음 |
| 월지 | "발굴로 '월지'임이 밝혀졌다" | **문헌 근거**다(최치원 「지증화상비명」 + 삼국사기 5건). '월지' 명문 유물은 없음 |

| 문무대왕릉 | "뼈를 바다에 뿌렸다" | 산골은 현대 학설. 삼국유사는 `葬骨處`(뼈를 간직한 곳)라 적음 |
| 대릉원·진평왕릉·원성왕릉 | 능 위치를 확정 사실로 서술 | 모두 **후대 비정**. 원문 표기(흥륜사 동쪽 / 한지 / 곡사)를 밝히고 "전해 온다"로 서술 |

## 서술 원칙

- **출전을 섞지 않는다.** 삼국사기에만 있는 서술(시림→계림 개명, "그 땅이 뒤에 월성이 됨")은
  이야기 안에서 어느 사서의 기록인지 밝힌다.
- **후대 비정·학설을 확정 사실로 적지 않는다.** 능 비정, 첨성대 용도, 오릉 피장자 등.
- **대사는 각색이되 사건은 각색하지 않는다.** 원문에 없는 사건·정보를 지어내지 않는다.
  원문에 대사가 없는 이야기(오릉)는 나레이션만으로 구성했다.

2026-08-31 확장분(석굴암~진평왕릉 18곳)은 `searchKeyword2` + `detailCommon2` 실호출로
검증했다(전부 `contentTypeId=12`, 좌표·대표 이미지 존재 확인). 확장분 특이사항:

- **대릉원(126214)** — TourAPI 항목명이 "천마총(대릉원)"이다. 이야기(미추왕 죽엽군)의
  무대인 미추왕릉(죽현릉)은 대릉원 경내에 있으므로 같은 항목에 연결했다.
- **영지(3090456)** — 아사달·아사녀 이야기는 삼국유사에 없는 **근대에 정착된 전설**이다.
  인물명은 현진건 소설 '무영탑'(1939)에서 굳어진 것으로, `sources` 와 인물 설명에
  명시해 두었다. 감수 시 표기 수위를 확인할 것.
- **문무왕 관계 보정** — 기존 `king_munmu` 의 "을제 신하" 관계는 연대가 맞지 않아
  (을제는 선덕여왕대 재상) 김춘추·문희·신문왕 가족 관계로 교체했다.

## 감수 체크리스트 (사람)

- [ ] 각 이야기의 **사실 vs 각색** 경계 확인 — 대사는 모두 각색이며, 사건/인물은 출처(`sources`) 기반인지 검토
- [ ] `sources` 표기가 실제 출전과 일치하는지 확인 (삼국유사/삼국사기 편명)
- [ ] 인물 생몰년·관계 라벨의 정확성 확인 (예: 경애왕·견훤 연대)
- [ ] 역사 왜곡 소지가 없는지, 민감한 해석을 단정적으로 적지 않았는지 확인

## 인물 초상 이미지

`characters.json` 의 `portrait` 경로(`assets/portraits/*.png`)에 해당하는 이미지는 아직 없다.
UI 는 이미지 로드 실패 시 **이름 첫 글자 아바타**로 폴백하므로 앱은 정상 동작한다.
배포 전 일러스트/아이콘을 `assets/portraits/` 에 채우면 된다.
