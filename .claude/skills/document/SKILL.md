# Documentation Skill

## 적용 범위
`README.md`를 **제외한** 모든 문서 파일(`.md`, 스킬 파일, 규칙 파일, 플랜 파일)을 작성하거나 편집할 때 이 스킬을 적용합니다.

## 언어 규칙

### MUST
- 모든 문서 파일은 **한국어**로 작성되어야 함.
- `SKILL.md` 파일은 예외 없이 항상 한국어로 작성되어야 함.
- 유일한 예외는 `README.md`이며, 이는 영어로 작성될 수 있음.
- 기존 영어 문서를 마이그레이션할 때는 기술적 정확도를 유지하면서 한국어로 번역함.
- 외부 소스에서 스킬/문서를 설치하거나 가져온 직후(`npx skills add` 등), 해당 파일이 영어로 작성되어 있다면 **즉시 한국어로 번역**하여 덮어쓸 것. 설치 대상에는 `SKILL.md`뿐 아니라 `references/`, `assets/` 등에 포함된 모든 `.md` 문서를 포함함.

### MUST NOT
- 단일 문서 내에 한국어와 영어를 혼용하지 않을 것 (README.md 제외).
- 코드 식별자, 파일 경로, CLI 명령어, 규범 키워드(`MUST`/`MUST NOT`/`SHOULD`/`MAY`)는 번역하지 않고 원문 그대로 유지할 것.
- 외부에서 설치한 스킬을 영어 원문 그대로 방치하지 않을 것.

## Humanizer 연계

### MUST
- 한국어 문서를 작성하거나 편집한 뒤에는 `humanizer` 스킬을 항상 적용해 AI 작문 패턴(쉼표 과다, 명사 과다, AI 유행어, 영어식 구문, 단조로운 문장 리듬 등 24가지 패턴)을 제거한다.
- 외부 스킬을 한국어로 번역한 직후에도 `humanizer` 를 적용해 번역체 잔흔을 제거한다.
- 규범 블록(`MUST` / `MUST NOT` 리스트) 자체는 정밀성을 위해 `humanizer` 적용 대상에서 제외하되, 산문 단락과 설명 텍스트에는 적용한다.

### MUST NOT
- `humanizer` 적용을 생략한 채 문서를 확정하지 않는다.
- `humanizer` 적용이 의미(사실·규칙·식별자)를 바꾸도록 허용하지 않는다.

## AI 최적화 작성 규칙

### 구조

#### MUST
- 모든 문서는 단일 문장의 목적 서술로 시작함 (이 파일이 무엇을 위한 것인지).
- 평면적 계층 구조 사용: H2(`##`) 섹션을 선호하고 깊이 중첩된 헤딩은 지양. 최대 깊이는 H3(`###`).
- 에이전트가 무조건 따라야 하는 규칙에는 `MUST` / `MUST NOT` 제약 블록 사용.
- 개별 항목에는 글머리 목록 사용. 순차적 단계에만 번호 목록 사용.
- 각 섹션 내에서 가장 중요한 정보를 먼저 배치 (역피라미드).
- 각 글머리는 하나의 아이디어만 담음. 하위 글머리가 필요한 경우 한 단계까지만 중첩.

#### MUST NOT
- 긴 산문 단락을 작성하지 않을 것. 글머리 또는 제약 블록으로 분리.
- 모호한 한정어("일반적으로", "보통", "할 수도 있음") 사용 금지. 구체적인 조건과 결과를 명시.
- 동일한 규칙을 여러 섹션에 반복하지 않을 것. 한 번만 명시하고 필요시 참조.

### 명확성 & 정밀성

#### MUST
- 일관된 용어 사용 — 용어는 한 번 정의하고 이후 동일한 단어를 재사용.
- 파일 참조 시 프로젝트 루트에서의 전체 상대 경로 사용 (예: `lib/data/util/converter_date_time.dart`).
- 코드 패턴을 참조할 때는 정확한 구문을 보여주는 최소한의 코드 블록 포함.
- "무엇을 해야 하는지" (규칙)와 "왜" (맥락/근거)를 분리. 근거는 필요한 경우 `## 배경` 섹션에 작성.

#### MUST NOT
- 명확한 선행사 없이 모호한 대명사("이것", "그것", "해당") 사용 금지.
- 불필요한 채움 구문("~하기 위하여", "참고로", "앞서 언급한 바와 같이") 사용 금지.
- 논평이나 의견을 추가하지 않을 것 — 사실과 규칙만 명시.

### 코드 블록

#### MUST
- 언어 식별자를 항상 명시 (예: ` ```dart `, ` ```bash `).
- 코드 블록은 최소화 — 전체 파일이 아닌 관련 패턴만 표시.
- 코드 블록 내 주석은 핵심 사항을 강조하기 위해서만 사용하고, 서술하는 용도로 사용하지 않음.

### 상호 참조

#### MUST
- 다른 문서에 의존하는 경우 상대 경로로 링크: `See [Data Layer 가이드](../data-layer/SKILL.md)`.
- 참조 파일 목록은 하단의 `## 참조 파일` 섹션에 작성.
