# Unknown: Known/Unknown 사분면으로 사각지대 드러내기

이 스킬은 **4사분면 프레임워크**를 사용하여, 가설 기반 질문을 통해 전략·계획·의사결정의 숨겨진 가정과 사각지대를 발견합니다.

**항상 AskUserQuestion 도구를 사용할 것** — 명확화 질문을 일반 텍스트로 묻지 않는다.

## 핵심 메커니즘

**가설로서의 선택지**: 개방형 질문 대신, 검증 가능한 가설을 객관식 선택지로 제시한다. 좋은 선택지를 설계하는 것 자체가 분석 작업의 80%다.

**3라운드 패턴**:
- **R1** (3~4개 질문): 전체 4사분면에 걸쳐 초기 분류를 검증한다
- **R2** (2~3개 질문): R1 답변을 바탕으로 취약한 지점을 집중 탐색한다
- **R3** (2~3개 질문): 선택적으로 실행 세부사항을 다룬다

질문은 항상 이전 답변에서 *생성*된다. 사전에 준비된 질문이 아니다.

## 4사분면

1. **Known Knowns** — 체계화하고 최적화한다
2. **Known Unknowns** — 성공 기준이 있는 실험을 설계한다
3. **Unknown Knowns** — 존재하지만 활용되지 않는 자산을 레버리지한다
4. **Unknown Unknowns** — 새로운 리스크를 위한 모니터링을 구축한다

## 프로세스

1. 제공된 문서에서 목표와 가정을 추출한다
2. 활용되지 않는 자산(도구, 전문성, 과거 패턴)을 탐색한다
3. 초기 사분면 분류 초안을 작성한다
4. 구조화된 AskUserQuestion 도구(일반 텍스트 질문 절대 금지)로 전체 라운드에 걸쳐 7~10개의 응답을 수집한다
5. 리소스 배분, 실험 설계, "중단해야 할 것" 항목이 포함된 플레이북을 출력한다

**핵심 원칙**: "초기 사분면은 수정되기 위한 것이다" — R1은 초안을 확인하는 게 아니라 도전하기 위해 존재한다.

## 사용 시점

- 새 프로젝트나 이니셔티브를 계획할 때
- 전략이나 의사결정을 평가할 때
- 사후 검토(post-mortem) 또는 회고
- 리스크 평가

요구사항 명확화는 **vague** 스킬을 사용하라. 내용 vs 형식 재구성은 **metamedium** 스킬을 사용하라.

## 규칙

1. **가설, 개방형 질문 아님**: 모든 선택지는 그럴듯한 해석이어야 한다
2. **수정을 위한 초안**: 초기 사분면은 도전받기 위한 것이다
3. **답변에서 질문 생성**: 각 라운드는 이전 응답을 기반으로 구성된다
4. **총 7~10개 질문**: 전체 라운드에 걸쳐
5. **항상 AskUserQuestion 사용**: 일반 텍스트 질문 금지
